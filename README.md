# SmartLash

美在眉睫——融合视觉检测与智能推荐的眼妆双端服务系统。

## 项目简介

“美在眉睫”是一款面向眼妆场景的双端智能服务系统，集微信小程序与网页端于一体，融合计算机视觉、AI 推荐与智能体咨询技术，实现眼部分析、产品适配、知识问答与个性化服务闭环。

系统通过采集用户正面与眼部图像，分析眼型、睫毛长度、弯曲度等关键参数，并结合产品库完成适配推荐，降低用户挑选难度与退换货率，提升化妆体验，在美妆电商领域兼具市场竞争力与应用前景。

## 核心功能

1. 眼部图像采集：支持用户上传或采集眼部图像。
2. 特征检测分析：自动完成眼部区域定位、关键点检测与特征提取，分析眼型、睫毛长度、弯曲度等参数。
3. 智能产品推荐：结合检测结果、推荐模型与产品信息库，输出适配的眼妆产品推荐结果。
4. 智能体咨询服务：基于大模型实现眼妆知识问答、产品使用建议与个性化咨询。
5. 双端一致交互：微信小程序与网页端实现一致的核心功能与业务流程，满足不同平台用户使用需求。

## 技术架构

1. 前端架构：微信小程序原生框架与 Vue + Vite 网页前端。
2. 后端架构：Django 服务接口，负责图像处理、特征分析、推荐计算与业务调度。
3. 视觉检测模块：利用 dlib 关键点检测、图像处理算法与深度学习模型完成眼部区域定位和睫毛特征分析。
4. 推荐模块：基于眼部参数与产品信息库实现适配推荐。
5. 智能体模块：引入大模型驱动的智能咨询能力，实现知识问答、效果解释和个性化交互。

## 项目亮点

1. 双端同构：采用微信小程序与网页端双端部署方案，在不同平台实现一致的核心功能与交互流程。
2. 多技术融合：将计算机视觉特征分析、AI 推荐与智能体咨询结合到同一系统中，实现检测、推荐、问答协同联动。
3. 智能咨询：系统不仅具备参数识别和产品适配能力，还可提供眼妆知识问答、产品使用建议和个性化咨询服务。
4. 场景闭环：围绕“图像采集-特征分析-产品推荐-智能咨询”构建完整服务闭环，提升用户选购效率与使用体验。

## 目录结构

```text
.
├── SmartLash_后端/          # Django 后端与图像分析接口
├── SmartLash_网页前端/      # Vue + Vite 网页端
├── SmartLash_小程序前端/    # 微信小程序前端
├── 算法代码和模型/          # 算法代码、配置与压缩模型权重
├── 启动SmartLash网页.py     # 一键启动网页端
└── 启动SmartLash小程序.py   # 一键打开微信小程序项目
```

## 运行前提

1. 网页端运行前提：
   - Python 3
   - Node.js / npm
   - 当前电脑可以正常联网安装 Python 依赖和 npm 依赖

2. 小程序端运行前提：
   - 已安装微信开发者工具

3. 说明：
   - 微信开发者工具只影响小程序端运行，不影响网页端启动。
   - 网页端首次运行时，脚本会自动创建后端 `.venv`、安装 Python 依赖、安装前端 npm 依赖并构建前端。
   - 运行所需模型权重已压缩在 `算法代码和模型/模型权重.zip`，启动脚本会在运行前自动解压。

## 运行方式

### 网页端启动

```bash
python 启动SmartLash网页.py
```

运行后会自动：

- 检测并解压模型权重
- 检测并安装后端依赖
- 检测并安装前端依赖
- 构建网页前端
- 启动 Django
- 自动打开登录页

默认访问地址：

```text
http://127.0.0.1:8002/login?fresh=1
```

后端也可以单独启动：

```bash
cd SmartLash_后端
python manage.py runserver 127.0.0.1:8002
```

### 小程序端启动

```bash
python 启动SmartLash小程序.py
```

运行后会自动：

- 检测并解压模型权重
- 启动微信开发者工具
- 自动打开 `SmartLash_小程序前端` 项目目录

## 可选环境变量

智能问答和 OSS 上传相关密钥不会提交到仓库。需要启用时，可在系统环境变量或 `.smartlash/local.env` 中配置：

```text
DEEPSEEK_API_KEY=your_deepseek_api_key
ALIYUN_OSS_ENABLED=true
ALIYUN_OSS_ACCESS_KEY_ID=your_access_key_id
ALIYUN_OSS_ACCESS_KEY_SECRET=your_access_key_secret
ALIYUN_OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
ALIYUN_OSS_BUCKET_NAME=your_bucket_name
```

## 模型权重说明

为便于 GitHub 上传和项目传输，运行所需权重统一压缩在：

```text
算法代码和模型/模型权重.zip
```

该文件使用 Git LFS 管理。首次运行启动脚本时会自动解压到代码需要的原始路径。

仓库不提交 `.venv`、`node_modules`、构建产物、运行日志、缓存文件和解压后的模型权重原文件。需要运行时由启动脚本自动生成或恢复。
